# virome_analysis_pipeline 分析流程审查（2026-10-10）

## 0. 总体评价与审查边界

审查对象：`virome_analysis_pipeline/` 中已给出的变异分析、AF 矩阵、群体遗传与 QST 路径。本文仅整理已有实测证据并对照当前源码定位；不新增运行探针、不重跑真实数据、不扩展到历史支线。`capheine`/`hyphy` 等不在当前主链的旧模块不作为本报告发现。

**总体判断：管线具备可用的变异与群体分析组件，但现有若干输出字段的统计含义与实际计算不一致，且 sites-only AF 回退会改变样本/位点的缺失语义；π、唯一 reads 与“单倍型”结论不宜未经修正或降格表述直接用于生物学结论。**

证据口径：
- **静态高可信**：由当前源码分支和消费者链路直接确认。
- **已有实测**：复用此前审查已获得的最小反例/桩结果；本文不声称重新执行。
- **科研解释风险**：代码语义已确认，但真实队列的受影响比例未重新量化。

严重级别：**P0**=会直接改变核心统计结论；**P1**=流程/字段可靠性错误；**R-major**=研究设计或统计解释限制；**R-minor**=图表或术语表达问题。以下 10 项：P0 1 项、P1 6 项、R-major 3 项。

## 1. 实现缺陷

### V01 · P1：Salmon EM 估计数写入 `Uniq_Reads`，默认唯一 reads 门槛因而不是唯一性筛选

- **证据**：`batch_virus_depth.py:393` 从 Salmon `quant.sf` 读取 `NumReads`，即 EM 分配计数；`:408-412` 将同一 `reads` 写入 `EM_Reads` 和 `Uniq_Reads=int(reads)`，并固定 `Multi_Reads=0`。`:567` 随后以 `Uniq_Reads/(Uniq_Reads+Multi_Reads)` 计算 `Unique(%)`；`:616` 的 `filter_base` 用 `Uniq_Reads >= min_uniq_reads` 作默认入选条件。`auto_known_virus.py:178` 将 `--min_uniq_reads` 描述为“unique reads”。
- **触发**：默认 `--tool salmon`，且使用默认 `--min_uniq_reads 10`；EM 分配到参考的数量被当作唯一命中数，`Multi_Reads=0` 使唯一比例看起来为 100%。
- **后果**：字段名、过滤门槛及下游 `Unique(%)` 失去“唯一比对”的含义，低特异性/多重匹配的 EM 计数仍能过唯一 reads 门槛。
- **可信度**：静态高可信；已有实测确认该默认路径把 EM 计数写到 `Uniq_Reads` 且 `Multi_Reads=0`。
- **建议/验收**：伪比对模式不要伪造唯一/多重计数；将 EM 估计数与唯一计数分列，或在该模式下禁用/改名唯一 reads 门槛。验收应覆盖共享 read 在多个参考间 EM 分配的样本，确认不会被报成 100% unique。

### V02 · P1：AF fallback 缺少样本 AF 文件时整样本被排除，矩阵样本集缩小且仅控制台提示

- **证据**：`virus_vcf_pipeline.py:331-335` 在找不到某输入 VCF 对应 AF 表时仅加入 `skipped` 并 `continue`；只有成功解析 AF 表后 `:358` 才将 Run 加入 `sample_names`。`:362-369` 仅打印跳过数并检查剩余样本/位点，`:371-390` 只对保留样本构矩阵。AF fallback 的主管线调用在 `:1834-1840`。
- **消费者**：AF fallback 生成的矩阵进入 `virus_vcf_pipeline.py:1858-1864` 距离计算，以及之后的树、PCA、LD、PopGen；外部 QST 脚本也接受 `snp_matrix.tsv`/`Matrix_05.csv` 作为输入（`utils/virus_haplotype_qst.py:25-28,262-264`）。
- **触发**：某个样本有 VCF，但对应 `allele_frequencies.tsv` 缺失或解析失败；该样本不会成为输出矩阵行，而非以明确缺失状态保留。
- **后果**：下游样本集合与输入 VCF 集合不一致；若只看矩阵本身，容易把被静默排除的样本误认为未纳入分析。
- **可信度**：静态高可信；已有实测确认 no-AF 样本被跳过。
- **建议/验收**：失败样本名单应成为强制、可机器读取的输出；关键群体分析默认遇到输入样本缺 AF 时应 fail-fast，或保留全 NA 行并让消费者显式处理。验收时输入 VCF 数与矩阵样本数不符必须报错/列明差集。

### V03 · P0：`Pi` 实际计算为“非主等位读段比例”，不是成对核苷酸多样性

- **证据**：`batch_virus_variants.py:351-356` 对每个覆盖位置计算 `pi_list.append((tot - max(c.values())) / tot)`，`:361` 再对位点求均值；这里是 `1 - p_max`，并非 `1 - Σp_i²` 或成对差异率。`:312-315` 对进入计算失败的样本默认 `Pi=0.0`。
- **已有反例**：9A/1G 时该函数值为 0.1；双等位成对差异率 `2×0.9×0.1` 为 0.18，二者不相等。该反例及函数值来自既有实测，不在本文重跑。
- **消费者**：`batch_virus_variants.py:870` 按 reads 加权汇总样本 `Pi`，`:912-923` 将 `Pi_avr` 写入变异汇总（该表再被下游报告消费）。
- **触发**：运行变异指标统计并将输出列 `Pi`/`Pi_avr` 解释为核苷酸多样性。
- **后果**：多态位点的多样性系统性低估或错估；9:1 示例即已改变统计量。零值回退还会与真实低多样性混为一谈（见 V04）。
- **可信度**：已有最小反例，高；公式与报告字段的语义不匹配为静态高可信。
- **建议/验收**：按观察到的碱基频率实现 pairwise diversity（明确是否有限样本校正、N 的处理及位点纳入规则），或改名为主等位之外的 reads fraction。验收至少覆盖 9:1、5:5、单态、多等位、含 N 五组手算用例。

### V04 · P1：缺少 BAM `MD` 标签时，多项指标异常被吞并为默认零值

- **证据**：指标字典在 `batch_virus_variants.py:312-315` 先将 `read_count`、覆盖、`Pi`、`Shannon`、`ANI` 等初始化为 0；`:338` 调用 `get_aligned_pairs(..., with_seq=True)`，缺少 `MD` 时该路径会抛异常；外层 `:318-319,364-365` 捕获后直接 `pass`，最后 `:367-368` 仍返回零值字典。BAM 输入路径 `:282-296` 没有验证或补齐 `MD` 标签；缺标签时的影响由既有无 MD 桩结果确认。
- **消费者**：`batch_virus_variants.py:870-872,912-923` 按 reads 加权聚合并写出这些字段（如 `Pi_avr`）；零值随成功行写入结果，不会标记为“不可计算”。
- **触发**：输入/生成 BAM 无 `MD` 标签，指标函数触发 `with_seq=True` 异常；已有无 MD 桩实测观察到相关指标回落为零且异常未传播。
- **后果**：技术性不可计算被表示为生物学上的零变异/零多样性，可能压低病毒级平均指标，并让下游无法区分失败与真实零值。
- **可信度**：静态高可信；无 MD 桩为已有实测，本文未重新运行。
- **建议/验收**：在上游确保 BAM 的 MD 标签完整，或使用不依赖 MD 的碱基重建路径；失败时输出 NA/状态码并显式记录样本，不得静默保留零。验收缺 MD 与有 MD 的同一 BAM 对照，缺标签必须报不可计算而非全零成功。

### V05 · P1：过滤结果为空时不创建 `high_conf` 文件，编排器回退并消费未过滤的 `best_summary`

- **证据**：`utils/filter_summary.py:217-220` 计算 passed；`:279-283` 仅在 `len(passed)>0` 时写输出，空结果时明确不创建文件。`auto_known_virus.py:423-425` 的 `get_summary()` 仅检查 `high_conf.exists()`，不存在就返回未经该过滤步骤筛选的 `best_summary`；`:551-553` 即使过滤脚本成功，也会标记 filter stage 完成。Stage 3 `:567-575` 和 Post `:629-653` 都消费 `get_summary()`。
- **触发**：当前过滤条件没有任何记录通过，`high_conf.summary.tsv` 不落盘；随后 variants/post 等阶段仍继续运行。
- **后果**：过滤器得出“零高置信记录”，下游却改用未过滤候选继续分析，过滤门槛被绕过且日志/阶段状态看不出回退。
- **可信度**：静态高可信。
- **建议/验收**：空过滤结果应写带表头的空文件或明确状态文件，编排器不得回退到更宽松输入；需要回退时必须显式 opt-in 并在产物中标示。验收 all-rejected 测试中 Stage 3/Post 不得收到 `best_summary`。

## 2. AF / PopGen 口径与科研解释

### V06 · R-major：sites-only AF 将未记录位点固定解释为参考态，不能据此声称“已 callable”或估算缺失率

- **证据**：`virus_vcf_pipeline.py:317-325` 明确约定“有记录但低于阈值 / 未记录 → 0（显式参考态）”；`:372-380` 二值与连续 AF 矩阵从零初始化，只覆盖实际出现的 sample-site 记录。其 sites-only QC `:399-402,431-439` 将 `n_missing=0`、`missing_rate=0.0` 固定输出；主流程 `:1797-1803` 还声明 AF fallback 不支持 `--max-snps/--max-missing` 过滤并忽略这些参数。
- **重要边界**：**不把“未记录=参考态”本身报为实现 bug**，这是源码明确写定的编码约定。问题是该约定不能证明未记录位点确实被充分覆盖、已 callable；QC 的零缺失率也不是 callability 证据。
- **触发**：sites-only 输入经 AF fallback 后，下游把 0/缺省 AF 当作已观测的参考态，并据 QC 表解释为无缺失或通过缺失率筛选。
- **后果**：样本覆盖不均或低覆盖位点可能被包装成参考基因型；缺失/可调用率过滤无法在此路径上发挥作用，距离、PCA、π 和 QST 模式的解释受影响。
- **可信度**：源码约定静态高可信；真实输入的 callability 覆盖未重新量化。
- **建议/验收**：保留这项既定编码时，结果必须标成“未记录按参考态处理”，不能标成实测 genotype/callable。若研究问题依赖缺失率或可调用性，需单独提供每样本×位点深度/调用状态矩阵；验收应证明低覆盖/未调用可与真实 AF=0 区分。

### V07 · P1：AF fallback 可把 indel 放进声称为 biallelic-SNP 的矩阵与 PopGen 输入

- **证据**：标准合并 VCF 路径在 `virus_vcf_pipeline.py:1754-1765` 通过 `bcftools view -m2 -M2 -v snps` 明确只保留双等位 SNP，PopGen 代码注释也以纯双等位 SNP 为前提（`:1176-1178`）。但 AF fallback 在 `:341-355` 只要求 `CHROM/POS/REF/ALT/ALT_FREQ`，直接以 REF/ALT 构建位点标签，没有 SNV 长度或类型过滤；主管线 `:1834-1840` 进入 fallback 时直接将其矩阵交给后续分析。上游 `batch_virus_variants.py:463-465` 的 LoFreq 分支启用 `--call-indels`，而 `:502-505` 从过滤 VCF 导出 AF 表。
- **触发**：sites-only/无 0 态路径启用 AF fallback，且 per-sample AF 表含 indel。
- **后果**：矩阵虽被称为 SNP 矩阵，但可能混入 indel；`compute_sliding_window_popgen` 将每个矩阵列按一个 biallelic 位点计算（`virus_vcf_pipeline.py:1169-1185`），与“每碱基 SNP 多样性”口径不一致，QST/LD/距离也可能纳入非 SNP 特征。
- **可信度**：静态高可信；indel 输入存在与否依 caller/队列而定。
- **建议/验收**：AF fallback 需与 GT 路径统一 SNP 过滤规则，或给 indel 单独定义统计单位并改名输出。验收把一条双等位 indel 加入 AF 表，确认 SNP 矩阵/π 的位点集合不变或明确标注纳入规则。

## 3. QST 输出与术语边界

### V08 · P1：`--af-bins` 低档 token 与图例错位，且实际编码没有产生图例中的 `0`

- **证据**：`utils/virus_haplotype_qst.py:184-190` 将矩阵初始化为 `grades[0]`，然后按阈值依次覆盖；以 `0.05,0.25,0.75` 为例，实际 `<0.25` 都是 `L`、`0.25–0.75` 是 `M`、`>=0.75` 是 `H`。但 `_bins_legend` 在 `:196-201` 声明 `<0.05='0'`、`0.05–0.25='M'`、`0.25–0.75='H'`、`>=0.75='L'`。热图标题与 token 色标在 `:468-504` 直接使用该 legend。
- **触发**：以 `--af-bins` 生成 token 矩阵、QST 聚类或热图。
- **后果**：低于首阈值的 AF 也被赋 `L`，而图例说是 `0`；其它档位亦错位。除图示误导外，token 模式和聚类结果也与用户指定的分级语义不同。
- **可信度**：静态高可信。
- **建议/验收**：先将低于首阈值的值编码为 `0`，阈值区间再依次赋 `L/M/H`，并令图例与编码共用同一映射。用 `<0.05`、`0.05`、`0.25`、`0.75` 边界值核对 token、QST 模式和图例一致。

### V09 · R-major：QST 是跨样本 AF token 模式的聚类，不是经相位解析的病毒单倍型

- **证据**：脚本输入为样本×位点数值矩阵（`utils/virus_haplotype_qst.py:76-100`）；对每个样本逐位点按 AF 阈值离散化（`:177-193`），将整行 token 元组作为模式并按 Hamming 距离连通分量聚类（`:223-252,330-351`），而结果被命名为 `QST`/“单倍型”并输出成员表（`:4-23,360-375`）。该路径没有 reads 跨位点连锁、长读段或相位信息输入。
- **触发**：把 `QST_Definitions.tsv`、QST 热图或组间 QST 频率直接解释成病毒真实单倍型/准种谱系。
- **后果**：输出仅代表“检测位点 AF 模式相似簇”；没有位点相位就无法推断各变异是否在同一条病毒基因组上。阈值离散化也使簇定义依赖 AF cutoffs 与受检位点集合。
- **可信度**：静态高可信；属于分析对象定义边界，不是实现运行错误。
- **建议/验收**：若保留现算法，改用“AF-profile cluster/QST pattern”并在结果与图注中说明非相位单倍型；要声称真实 haplotype/准种需加入可连接位点的读段相位证据，并验证阈值/位点集敏感性。

### V10 · R-major：池化样本的位点边际 AF 无法恢复样本内跨位点连锁结构

- **证据**：`utils/virus_haplotype_qst.py:177-193` 独立将每个位点 AF 映射为 token；`:223-233` 计算的是两个样本 token 行之间共享位点的 Hamming 距离。此输入保留各位点边际频率，不含跨位点联合等位基因计数。
- **触发**：用 pooled sequencing 的 AF 矩阵推断单样本内部 quasispecies composition、完整 haplotype 数量或传播单元。
- **后果**：不同的真实相位/单倍型组合可产生完全相同的边际 AF 向量；矩阵模式聚类不能辨识这些组合，也不能用样本间聚类结果替代样本内病毒基因组相位。
- **可信度**：统计可辨识性限制，高；真实队列具体影响未量化。
- **建议/验收**：把 QST 限定为跨样本 AF 模式分组，不报告为单个样本的准种 haplotype 组成；如目标是准种结构，补充长读段/单分子相位、haplotype reconstruction 或明确的深度与连锁模型，并在报告中给出可识别假设。

## 5. 覆盖限制与不报项目

- 本报告仅列当前分析路径与已有证据；未重新运行全链路、第三方工具或真实队列，也未重新估计缺失 AF、indel、缺 MD BAM 的样本比例。

- 不把未进入当前主链的旧 Capheine/HyPhy 支线作为当前缺陷；不根据缺少依赖或未经验证的外部程序行为推断错误。
