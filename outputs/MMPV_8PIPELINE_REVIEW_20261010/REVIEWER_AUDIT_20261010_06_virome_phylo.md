# virome_phylo_pipeline 审稿视角复核报告（2026-10-10）

## 0. 总体评价与证据边界

本轮聚焦此前探针已复现的统计口径、阶段数据契约与定年门控问题；不再启动新测试、外部工具或联网查询。管线已有阶段依赖校验、分阶段状态记录、输入指纹等值得保留的机制；但本轮确认的若干问题会造成统计量符号/数值错误、重组样本集不一致，或允许未经 DRT 通过的 BEAST 定年，结果不应未经修正直接作为论文证据。

**证据说明**：下文“已实测”指此前针对原函数的内存桩/表达式探针结果；不是完整生信工具端到端运行。行号按当前工作树源码核对。结论按触发条件限定到具体入口和消费者，不把单条路径问题泛化成全管线问题。

**审查与测试口径**：本轮记录的语法编译覆盖为 184 个 Python 文件、49,638 行；这只证明可编译，不等于功能测试。清点到的 99 个归档代码文件和 20 个测试文件均在 archive 路径，不能据此称当前活管线有 20 个有效测试。探针所用托管解释器入口/路径标注为 3.13.12，运行时 `sys.version` 实为 3.13.14；`METHODS.md:72` 写的是服务器 Python 3.10。该差异只说明探针环境与文档版本口径不一致，**不能据此推断服务器部署版本**；应在可复核记录中填写运行时版本。

严重级别：**P0** = 可翻转统计/科学结论或绕过关键方法门控；**P1** = 报告状态、统计校准或跨阶段可比性问题。可信度标记：**已实测** / **源码路径已核对**。

## 1. P0 — 可能改变结论

### P0-1 · batch/extract_dir 的 `align` 将原始 FASTA 当比对结果返回成功

- **证据**：`phylo_pipeline.py:1229-1232` 只要 `prep['combined_fasta']` 存在且路径不同于目标比对文件，就直接返回 `success=True`；实际调用 MAFFT 的代码在 `:1247-1252`。`force=True` 仅跳过已有产物缓存判断（`:1223-1227`），不会绕过上述提前返回。`process_virus` 在成功返回后将该路径登记为比对并继续（`:3210-3216`）。
- **触发范围**：`--extract_dir` 路径经过 clean 后，`combined_fasta` 是待比对原始序列时；不适用于 `--virus` / `--work_dir` 明确提供已有比对的直通场景。
- **后果**：原始/长度不等序列被标成 alignment，后续树、群体遗传、时钟等步骤可能在错误输入上运行或失败。此前内存桩探针确认原函数返回 raw `combined.fasta` 且 `success=True`；`force=True` 下 MAFFT 调用仍为 0 次。
- **可信度**：已实测 + 源码路径已核对。
- **建议验收**：明确区分“已有比对”与“原始序列”来源；batch 最小用例应实际调用 MAFFT、产出等长序列，并验证 `--force` 再次调用 MAFFT；已有比对入口继续保持不重比对。

### P0-2 · 默认删除重组子后的样本集未传递到 CAPHEINE 与 BEAST

- **证据**：默认 RDP5 策略生成删除重组子并重新比对的 FASTA（`phylo_pipeline.py:1306-1330`）；process 中只更新局部 `aln_file`（`:3263-3267`）。树/popgen/clock 等使用该局部路径。CAPHEINE 则取 `args.capheine_unaligned or prep['combined_fasta']`（`:1746-1755`）；BEAST 从 `results['outputs']['alignment']` 取 alignment（`:2697-2716`），而该字段在 align 阶段写入（`:3210-3214`），RDP5 后没有同步更新。
- **触发范围**：只针对 RDP5 默认 `drop + realign` 成功且相关 stage 同批执行的路径；`--rdp5_mask` 是区域置 N、并不删除序列，不能把本结论写成 mask 路径也“剔除了序列”。
- **后果**：树/popgen/clock 使用去重组子集合，而 CAPHEINE 仍可能纳入被删序列，BEAST 仍可能使用原 alignment。不同分析消费者对应的样本集合不一致，正选择与定年结果不能表述为基于去重组子数据。
- **可信度**：源码路径已核对；数据契约由局部变量与结果字典分离可直接确认。
- **建议验收**：记录 RDP5 输出样本 ID 集；按功能需要将过滤后的样本集同步到 CAPHEINE 原始序列输入和 BEAST alignment，或明确声明各消费者为何使用不同样本。验收逐 stage 比对 ID 清单，默认 drop 成功后不得在声称“去重组”的 CAPHEINE/BEAST 输入中重新出现已删 ID。

### P0-3 · Tajima’s D 混用每位点 π 与绝对 θW，符号和数值可翻转

- **证据**：`popgen_analysis.py:203-213` 的 `pi` 是每对序列的每位点差异率均值；`:222-224` 的 `theta_w = S/a1` 是绝对差异数尺度；`:226-238` 却直接以 `(pi - theta_w)` 作为 Tajima’s D 分子。
- **触发条件**：运行该模块的多样性分析；完整位点用例即可触发，不要求缺失数据。
- **后果**：D 分子量纲不一致，可能改变 Tajima’s D 符号，从而把群体扩张/稀有变异等解释导向相反方向。此前固定用例内存探针得到旧表达式 **-3.3128**，统一单位后的对照为 **+1.8931**。
- **可信度**：已实测 + 源码路径已核对。
- **建议验收**：确保 π 与 θW 在相同位点集合、相同每位点或绝对尺度上比较；用独立标准实现及无缺失/含缺失两组小型对照分别验证，需能解释当前用例的符号翻转。

### P0-4 · 排除参考/外群后，单倍型统计仍把被排除序列计入频数

- **证据**：样本数 `n` 和序列列表来自 `self.sequences_used`（`popgen_analysis.py:187-190`）；但单倍型频数循环遍历 `self.sequences`（`:240-246`），Hd 分母又使用前述排除后的 `n`。结果返回值将该结果作为 `haplotypes` 与 `Hd` 输出（`:248-258`）。
- **触发条件**：启用 `--exclude-reference` 或 `--exclude-ids`，且排除序列的单倍型与保留序列存在差异。
- **后果**：H/Hd 的样本集合与分母不一致；此前探针在排除参考的夹具上得到 `Hd=-2`，同一保留样本集合的正确值为 `Hd=0`。负 Hd 是不可能的统计量，也可能改变参考序列对多样性结论的影响方向。
- **可信度**：已实测 + 源码路径已核对。
- **建议验收**：多样性与单倍型统计统一使用 `sequences_used`；验收排除前后 `n`、H、Hd 与独立手算一致，Hd 始终位于 `[0,1]`。

### P0-5 · 位点法 Fst 删除 gap 后未同步删除对应群体标签

- **证据**：`popgen_analysis.py:312-321` 先按样本生成 `gvec`，但每个位点的 `col` 单独跳过 `'-'`；随后 `fst_one` 用未压缩的 `gv` 索引压缩后的 `col`（`:323-337`）。列中 gap 位于样本序列中间时，后续碱基与群体标签错位。
- **触发条件**：有内部/混合位置的 gap，且该位点被保留为多态位点；无 gap 的列不触发。
- **后果**：Fst 与置换检验的分组计数错误。此前最小内存夹具的位点 Fst 为 **1**，按各位点非 gap 样本正确配对的值为 **1/3**。
- **可信度**：已实测 + 源码路径已核对。
- **建议验收**：对每个列同时构造 `(碱基, 群体)` 非 gap 配对，再计算观测值和置换值；加入内部 gap、列首/列尾 gap、无 gap 对照，并与独立手算一致。

### P0-6 · FEL/MEME 的 BH q 值未参与阳性判定，`--fdr` 不控制结果

- **证据**：`selection_analysis.py:442-444` 计算 BH q 值；但 `:452-459` 的 FEL 判定使用 `beta > alpha and p < 0.05`，MEME 仅使用 `p < 0.05`，两者都不比较 q 值或 `fdr` 阈值。`cmd_parse` 将 `args.fdr` 传给解析函数（`:480-493`），但解析函数体没有使用该参数。
- **触发条件**：FEL/MEME 有多个位点且某位点原始 p<0.05 但 q 高于阈值。
- **后果**：未经多重检验控制的位点仍作为“正选择/阳性”输出；改变 `--fdr` 不改变阳性数量。此前探针确认 `q=0.5` 的位点仍被列为 positive，变更 FDR 参数无影响。
- **可信度**：已实测 + 源码路径已核对。
- **建议验收**：以 `q <= fdr`（或明确记录并采用预先声明的其他控制方式）作为显著判据；同一测试输入下 `fdr=0.01` 与 `0.1` 应按预期改变命中集合，且阳性字段与 q 列一致。

### P0-7 · DRT 的百分位通过判据在低随机化次数下可把非显著结果判为通过

- **证据**：`temporal_signal.py:280-291` 以 `percentileofscore(valid_r2, real_r2) >= 95` 作为 `passed`，未使用有限随机化次数的加一尾概率。主管线 `phylo_pipeline.py:1803-1804` 默认传入 10 次；`METHODS.md:25-28` 则写明正式研究取 100 次并以 95% 百分位为判据。
- **触发条件**：随机化次数少（探针覆盖 B=1、10、20），真实 R² 排名靠前/与随机值并列时。样本数太少时，排名百分位并不代表具有 5% 分辨率的随机化检验。
- **后果**：此前探针中 B=1/10/20 均得到 `passed=True`，但按 `(1 + # randomized >= real)/(B+1)` 的有限样本校正，分别为 **0.5、0.0909、0.0952**，后两者仍高于 0.05。若据此启动/报告定年，会把证据不足的时间信号误报为通过。
- **可信度**：已实测 + 源码路径已核对。
- **建议验收**：以明确的一侧经验 p 值及预先声明阈值判定；随机化次数不足以达到目标 p 值分辨率时返回 inconclusive，而非 pass。对 B=1/10/20 和大量随机化参考用例验证结论一致，并同步 METHODS、CLI 默认值与运行记录。

### P0-8 · BEAST 不受 DRT 结果门控

- **证据**：`STAGE_DEPS` 中 BEAST 仅依赖 tree，不依赖 clock（`phylo_pipeline.py:140-158`）；clock 会记录 `drt_passed`（`:1803-1811`），但 `run_phase_beast` 不读取或检查该值（`:2685-2716`）。方法章明确规定 DRT 未通过者不进入 BEAST 定年、不报告 TMRCA（`METHODS.md:25-28`）。
- **触发条件**：单独请求 BEAST（依赖闭包不会自动加入 clock/DRT），或同批 clock 的 DRT 为 false 后继续执行 BEAST。
- **后果**：方法章门控未落实，可能对 DRT 未通过或未计算的数据运行并报告定年。
- **可信度**：源码路径已核对；此前内存桩探针已实测 DRT=false 时 BEAST 路径仍可继续。
- **建议验收**：如果论文方法要求 DRT 门控，则将 clock/DRT 作为 BEAST 前置条件；DRT 未通过或无结论时阻止运行并明确记 blocked。分别覆盖 DRT=true/false/inconclusive，状态、退出码、TMRCA 输出均符合方法章。

## 2. P1 — 阶段成功状态不精确

### P1-1 · 只生成 BEAST XML 也会标记当前 stage 成功

- **证据**：`--skip_beast_run` 只跳过后验执行（`phylo_pipeline.py:2739-2741`），`run_phase_beast` 最终仍以 `not beast_pending` 设置成功（`:2879-2880`），调用方据此 `_mark('beast')`（`:3525-3531`）。此前内存桩探针已复现 XML-only 返回 `success=True`。已有 `_beast_ran()` 会在后续运行识别无后验产物并撤销旧 checkpoint 命中（`:3468-3481`），因此此处不声称该状态一定永久跳过后续正式运行。
- **触发条件**：使用 `--skip_beast_run` 只生成 XML。
- **后果**：本次执行结果把“生成输入文件”混同为“完成 BEAST 后验分析”，汇总 `stages_done` 会出现 BEAST，易被操作记录或人工误读。
- **可信度**：已实测 + 源码路径已核对。
- **建议验收**：XML-only 应返回专门的 skipped/pending 状态，不写 BEAST 后验完成标记；实际后验完成并有有效日志后才可标记 done。

## 4. 值得保留与不应扩大表述的边界

- `STAGE_ORDER` / 依赖图有启动期一致性检查；阶段完成状态及 BEAST 后验存在性有独立判定，修复时应保留这些防护。
- MAFFT 提前返回问题只确认在 `--extract_dir` 原始序列路径；不得概括成 `--virus` / `--work_dir` 已有比对也必然不正确。
- 重组样本集问题只确认默认 drop+realign 后，局部 `aln_file` 与 CAPHEINE/BEAST 分别消费原始或旧 alignment；不得写成 RDP5 所有输出消费者都失效。
- `concat` 已不在 stage 图中，相关工具函数不作为当前管线缺陷；不将历史/归档函数或测试计入现役 stage 行为。
- 语法编译通过不代表科学算法正确，也不代表具备有效测试；本报告不宣称运行过真实 MAFFT、IQ-TREE、HyPhy、BEAST 或完整端到端科研数据链。
