# 10 · 部署与运维

## 1. 一键部署

```bash
git clone https://github.com/zhangwenda0518/MMPV-RNA.git && cd MMPV-RNA
pixi install                     # 100 个 conda 包精确版本
conda env create -f envs/viralm.yaml -n viralm   # ViraLM 独立环境 (可选)
```
手动安装 (bioconda 无包, 见 `doc/MMPV_dependencies.md` A12): penguin / refineC / flye / PhaBOX2 / CHERRY / VirHunter / VirBot / ViraLM; BEAST/RDP5/PAML 按 ⑤ 文档单独部署。

## 2. 数据库 (50 项, 必需 25, 全量约 710GB)

```bash
python scripts/db_setup/mmpv_db.py list      # 清单
python scripts/db_setup/mmpv_db.py check     # 部署前体检
python scripts/db_setup/mmpv_db.py verify    # 校验现有库
python scripts/db_setup/mmpv_db.py down --apply
python scripts/db_setup/mmpv_db.py adopt --db-from ~/database --apply   # 迁移共享库根
python scripts/db_setup/mmpv_db.py link --apply                          # 旧路径兼容软链接
```
RVDB 派生库 (diamond/mmseqs/metabuli/CAT) 由 `virome_discovery_pipeline/build_virus_db.py` 现场构建。方案文档: `DATABASE_SETUP.md` + `doc/DB_DEPLOYMENT.md`。

## 3. 环境变量 (换环境只改一个)

| 变量 | 作用 |
|---|---|
| `MMPV_DB_ROOT` | 数据库根 (默认 /home/zhangwenda/database) — 覆盖它即迁移整批 |
| `MMPV_HOST_DB / MMPV_VIRUS_DB / MMPV_KRAKEN2_DB / MMPV_CHECKV_DB` | 派生库根 |
| `MMPV_EVE_REF_DB / MMPV_EVE_PV_DB / MMPV_EVE_ID2DIV / MMPV_EVE_RVDB_DB` | EVE 四库 |
| `MMPV_SALMON / MMPV_DIAMOND / MMPV_RAGTAG / MMPV_VIRBOT / MMPV_SAMTOOLS` | 工具可执行文件覆盖 |
| `MMPV_IO_LAYOUT` | I/O 布局 (legacy/standard), 子进程自动继承 |
