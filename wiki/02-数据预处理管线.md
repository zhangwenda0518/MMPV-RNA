# 02 · ② 数据预处理管线 (data_preprocessing_pipeline)

**定位**: reads 质量关。原始 FASTQ → 质控 (Fastp→Seqkit→Clumpify) → 去宿主 (Kraken2→比对→Ribodetector) → 可选覆盖度归一化 (BBNorm)。产出全下游 reads 唯一来源 `00b_HostDepleted/` (standard: `02_Preprocessing/02_HostDepleted/`)。

**主编排器**: `data_preprocessing.py` (`--stage clean deplete report [bbnorm]`, `all` = clean→deplete→report, **不含** bbnorm)
**worker**: `clean-data.py` · `host_depletion.py` · `run_bbnorm.py` · `preprocess_report.py` (报告)

## 阶段逐段解读

| 阶段 | 脚本 | 做什么 | 产出 |
|---|---|---|---|
| clean | `clean-data.py` | Fastp 质控 (Q30/dup 报告) → Seqkit 转 FASTA → Clumpify 聚类重排 (提压缩率+组装加速) | `01_CleanData/{1.fastp, 2.fasta, 3.clumpify}` (legacy: `00a_CleanData`) |
| deplete | `host_depletion.py` | Kraken2 分类 → **`keep_taxids=10239` 从 classified 池救回病毒 reads** → Bowtie2/HISAT2/Minimap2 比对去宿主 → Ribodetector/SILVA 去 rRNA | ★ `02_HostDepleted/` (legacy: `00b_HostDepletion`; B2 交接物) |
| report | `preprocess_report.py` | 汇总留存率 (低于阈值标 LOW_RETAINED) + 交接清单 + HTML | `preprocessing_summary.tsv` + ★ `assembly_ready.list` + HTML |
| bbnorm | `run_bbnorm.py` | 覆盖度归一化 (target=70, mindepth=2) — 仅共组装前深度差异大时才需要, `--stage all` **不包含** | `03_BBnorm/` (legacy: `00c_BBnorm`) |

## 关键参数

| 参数 | 默认 | 说明 | 出处 |
|---|---|---|---|
| `--input_reads` | — | 输入 FASTQ/FASTA 目录 (B1) | data_preprocessing.py |
| `--host_db` | — | 宿主库目录 (hostdb/ 或 host_reference 根, 自动下钻找子索引) | 同上 |
| `--aligner` | bowtie2 | 比对去宿主工具 (hisat2/minimap2 可选) | 同上 |
| `--seq_type` | rna-short | dna-short/rna-short/nanopore/pacbio | 同上 |
| `--rrna --rrna_tool` | off/ribodetector | rRNA 剔除开关与工具 (silva 备选) | 同上 |
| `--kraken2_confidence` | 0.2 | Kraken2 分类置信度 | 同上 |
| `--keep_rrna` | off | 保留 rRNA reads | 同上 |
| `--io-layout` | legacy | 布局开关; report 阶段显式传 clean/deplete 目录 (worker 默认值是 legacy 名) | 同上 |
| (clean 内部) `--skip_clumpify --dedup` | off | 跳过 Clumpify / fastp 自带去重 | 同上 |
