## `data_preprocessing_pipeline/host_depletion.py`

```text
usage: host_depletion.py [-h] [--tool {bowtie2,hisat2,minimap2}]
                         [--seq-type {dna-short,rna-short,nanopore,pacbio}] -k
                         KRAKEN2_INDEX [-x STEP2_INDEX]
                         (-I INPUT_DIR | -i INPUT [INPUT ...]) [-O OUTDIR]
                         [-o OUTPUT [OUTPUT ...]] [--jobs JOBS] [-t THREADS]
                         [-T TMP] [--logs_dir LOGS_DIR] [--force]
                         [--confidence CONFIDENCE] [-f {true,false}] [--rrna]
                         [--rrna_tool {ribodetector,silva}]
                         [--silva_index SILVA_INDEX] [--keep_rrna]
                         [--keep-taxids KEEP_TAXIDS] [--vmtouch]
                         [--no-memory-mapping] [--chunk_size CHUNK_SIZE]
                         [--rrna_report RRNA_REPORT]
                         [--steps {kraken2,align,rrna,kraken2,align,kraken2,rrna,align,rrna,kraken2,align,rrna}]
                         [-c CONFIG] [-d]

智能序列去宿主 + 去 rRNA 混合管道

options:
  -h, --help            show this help message and exit
  --tool {bowtie2,hisat2,minimap2}
                        步骤2精细比对工具 (--steps 含 align 时必需)
  --seq-type {dna-short,rna-short,nanopore,pacbio}
                        测序数据类型 (--steps 含 align 或 rrna 时必需)
  -k KRAKEN2_INDEX, --kraken2_index KRAKEN2_INDEX
                        Kraken2 宿主数据库
  -x STEP2_INDEX, --step2_index STEP2_INDEX
                        第二步工具索引前缀 (--steps 含 align 时必需)
  -I INPUT_DIR, --input-dir INPUT_DIR
                        输入目录自动扫描配对
  -i INPUT [INPUT ...], --input INPUT [INPUT ...]
                        指定一个或多个输入文件
  -O OUTDIR, --outdir OUTDIR
                        统一输出存放目录
  -o OUTPUT [OUTPUT ...], --output OUTPUT [OUTPUT ...]
                        手动指定输出路径
  --jobs JOBS           并发处理样本数
  -t THREADS, --threads THREADS
                        每样本分配线程数
  -T TMP, --tmp TMP     临时文件存放位置
  --logs_dir LOGS_DIR   底层运行日志及报告保存目录
  --force               强制重新运行所有样本
  --confidence CONFIDENCE
                        Kraken2 分类置信度阈值
  -f {true,false}, --filter {true,false}
                        true: 去除宿主; false: 提取宿主
  --rrna                开启 rRNA 剔除
  --rrna_tool {ribodetector,silva}
                        rRNA 剔除工具: ribodetector (默认, 仅 rna-short) / silva
                        (Bowtie2 比对 SILVA 库)
  --silva_index SILVA_INDEX
                        SILVA Bowtie2 索引前缀 (--rrna_tool silva 时必需)
  --keep_rrna           将分离出来的rRNA序列保存到 rrna/ 文件夹中 (默认丢弃)
  --keep-taxids KEEP_TAXIDS
                        Kraken2 中保留的 taxID (逗号分隔), 默认 10239=Viruses;
                        设为空则不保留任何分类reads
  --vmtouch             用 vmtouch 预热 DB 到 page cache (配合 --memory-mapping,
                        多样本并行时推荐, 避免首样本冷启动)
  --no-memory-mapping   禁用 --memory-mapping (每样本把 DB 读进堆内存; 仅单样本/调试, 多样本会爆内存)
  --chunk_size CHUNK_SIZE
                        ribodetector_cpu chunk_size (默认: 256)
  --rrna_report RRNA_REPORT
                        rRNA统计表名
  --steps {kraken2,align,rrna,kraken2,align,kraken2,rrna,align,rrna,kraken2,align,rrna}
                        消融实验：指定执行哪些步骤 (default: kraken2,align,rrna)
  -c CONFIG, --config CONFIG
                        透传额外参数
  -d, --debug           开启详细日志
```

```text
数据预处理 (清洗 + 去宿主)

  -i INPUT, --input INPUT
                        原始 FASTQ 目录
  -o OUTPUT_DIR, --output-dir OUTPUT_DIR
                        输出根目录 (生成 clean/ 和 host/ 子目录)

清洗 (clean-data.py):
  --skip-clumpify       跳过 Clumpify
  --dedup               启用 fastp 去重

                        与比对索引)
  --kraken2_db KRAKEN2_DB
                        Kraken2 宿主库 (与 --host_align_db 二选一)
  --host_align_db HOST_ALIGN_DB
                        宿主比对索引 (与 --kraken2_db 二选一)
  --tool {bowtie2,hisat2,minimap2}
                        比对工具
  --seq-type {dna-short,rna-short,nanopore,pacbio}
  --rrna                开启 Ribodetector 去 rRNA
  --confidence CONFIDENCE
                        Kraken2 置信度阈值
  --steps STEPS         去宿主步骤

流程控制:
  --skip-clean          跳过清洗
  --skip-depletion      跳过去宿主
  --force               强制重跑
  --threads THREADS     线程数
  --jobs JOBS           并行数
```

```text
usage: run_bbnorm.py [-h] -i INPUT -o OUTPUT [-t THREADS] [--max-mem MAX_MEM]
                     [-j JOBS] [--target TARGET] [--mindepth MINDEPTH]
                     [--keep-se-as-pe]

BBNorm 覆盖度归一化 (自动 PE/SE 识别)
```
