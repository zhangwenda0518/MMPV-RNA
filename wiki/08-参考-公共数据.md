## `public_metadata_pipeline/preprocess_unified.py`

```text
usage: preprocess_unified.py [-h] [--sra-dir SRA_DIR] [--fastq-dir FASTQ_DIR]
                             [--outdir OUTDIR] [--io-layout {legacy,standard}]
                             [--skip-convert] [--skip-clean] [--skip-deplete]
                             [--bbnorm] [--kraken2-db KRAKEN2_DB]
                             [--step2-index STEP2_INDEX]
                             [--host-species HOST_SPECIES]
                             [--host-taxid HOST_TAXID]
                             [--host-fasta HOST_FASTA]
                             [--host-work-dir HOST_WORK_DIR]
                             [--ncbi-api NCBI_API]
                             [--host-download-source {auto,datasets,ngd,ftp,gget}]
                             [--tool {bowtie2,hisat2,minimap2}]
                             [--seq-type {dna-short,rna-short,nanopore,pacbio}]
                             [--dedup] [--skip-clumpify]
                             [--clumpify-memory CLUMPIFY_MEMORY]
                             [--threads THREADS] [--jobs JOBS] [--tmp TMP]

统一数据预处理: convert → clean → [hostref] → deplete [→ bbnorm 可选]

options:
  -h, --help            show this help message and exit

输入 (二选一):
  --sra-dir SRA_DIR     包含 .sra 文件的目录
  --fastq-dir FASTQ_DIR
                        包含 .fastq.gz 文件的目录 (跳过 convert)

输出:
  --outdir OUTDIR, -o OUTDIR
                        输出根目录 (默认: ./preprocessed)
  --io-layout {legacy,standard}
                        I/O 目录布局: legacy=v3.0 现行名 (默认);
                        standard=统一编号(doc/IO_LAYOUT_DESIGN.md); 亦可
                        MMPV_IO_LAYOUT 环境变量

阶段控制:
  --skip-convert        跳过 SRA 转换
  --skip-clean          跳过清洗 (fastp+clumpify)
  --skip-deplete        跳过宿主剔除
  --bbnorm              可选: 去宿主后 BBNorm 覆盖度归一化 → 00c_BBnorm/ (默认不运行; 需 deplete
                        产物, 与 --skip-deplete 同用时要求 00b_HostDepletion/ 已存在)

宿主数据库 (已有库时指定):
  --kraken2-db KRAKEN2_DB
                        Kraken2 宿主数据库路径 (已有库时指定; 否则可用 --host-* 自动构建)
  --step2-index STEP2_INDEX
                        第二步比对索引前缀 (bowtie2/hisat2/minimap2; 已有索引时指定)

宿主参考构建 (可选: 自动构建索引后接续 deplete):
  --host-species HOST_SPECIES
                        宿主物种拉丁学名 (与 --host-taxid 同用)
  --host-taxid HOST_TAXID
                        宿主 NCBI Taxonomy ID
  --host-fasta HOST_FASTA
                        已有宿主基因组 FASTA (跳过 NCBI 下载)
  --host-work-dir HOST_WORK_DIR
                        宿主参考构建输出目录 (默认: <outdir>/host_reference)
  --ncbi-api NCBI_API   NCBI API Key
  --host-download-source {auto,datasets,ngd,ftp,gget}
                        宿主基因组下载通道: auto=datasets→ngd→FTP 自动回退; gget 走 Ensembl
  --tool {bowtie2,hisat2,minimap2}
                        比对工具 (默认: bowtie2)
  --seq-type {dna-short,rna-short,nanopore,pacbio}

clean 阶段:
  --dedup               fastp 内置去重
  --skip-clumpify       跳过 clumpify 聚类重排
  --clumpify-memory CLUMPIFY_MEMORY
                        clumpify 堆内存 (默认: 10g)

计算资源:
  --threads THREADS, -t THREADS
                        总线程 (默认: 40)
  --jobs JOBS, -j JOBS  并行任务数 (默认: 4)
  --tmp TMP             临时目录

示例:
  # 从 SRA 到 clean reads
  python preprocess_unified.py --sra-dir ./sra/ --outdir ./out/ \
      --kraken2-db ~/database/host_db/kraken2 \
      --step2-index ~/database/host_db/bowtie2/host

  # 已有 FASTQ, 跳过 convert
  python preprocess_unified.py --fastq-dir ./fq/ --outdir ./out/ \
      --skip-convert --kraken2-db ~/database/host_db/kraken2 \
      --step2-index ~/database/host_db/bowtie2/host
```
