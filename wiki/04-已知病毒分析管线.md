# 04 · ④ 已知病毒分析管线 (virome_analysis_pipeline)

**定位**: 对 ③ 产出的已知/高置信病毒做深度分析: 快速定量 → 高置信过滤 → 变异检测与注释 → VCF 后分析 → 12 步全长组装 → 提取 → SDT 相似性全景 → DVG/重组 → HTML 报告。
**主编排器**: `auto_known_virus.py` (9 阶段, `--stage all/detect/filter/variants/post/full/extract/similarity/dvg/report`)

## 9 阶段逐段解读 (输出目录 01_detection…09_report, standard: 30_Detection…38_Report)

| # | stage | 脚本 | 做什么 | 产物 |
|---|---|---|---|---|
| 1 | detect | `batch_virus_depth.py` | Salmon/Kallisto/Bowtie2 快速定量 + Poisson 过滤; 每病毒×样本读数/覆盖度 | ★ `01_detection/summary/all_viruses.best.summary.tsv` (+.raw.tsv) |
| 2 | filter | `filter_summary.py` | 高置信过滤 (reads/覆盖度双阈值) | `02_filtering/high_conf.summary.tsv` (后续阶段自动切用) |
| 3 | variants | `batch_virus_variants.py` | FreeBayes/iVar/LoFreq 变异检出 + 共识序列构建 | `03_variants/` (vcf/consensus/all_summary.tsv) |
| 4 | post | `virus_vcf_pipeline.py` + snpeff_*/snpgenie_master | VCF 可视化 + SnpEff 注释 + MAF 瀑布 + PCA/LD + SnpGenie dN/dS | `04_post_analysis/figs/` |
| 5 | full | `batch_virus_full.py` → `virus-full.py` | **OmniVirusAssembler V9.0 十二步全长组装**: SHIVER-like 融合实心骨架 → reads 级迭代抛光 (单碱基精度) → gmcloser + abyss-sealer 双引擎补洞 → 环化检测 (Circular=True) | `05_assembly/` |
| 6 | extract | `extract_full_fasta.py` | 最长 contig 提取 + 参考 N-fill (RNA 限 N<5% 才填); 实时更新 extraction_status.tsv | ★ `06_extraction/<病毒>/<样本>.full.fasta` (B4→⑤) |
| 7 | similarity | `virus_auto_pipeline.py` + `sdt_genus_matrix.py` | SDT 全长相似性热图 + MAFFT 层次聚类 (属级矩阵) | `07_similarity/` |
| 8 | dvg | `batch_virema_dvg.py` | ViReMa DVG/重组检测 + Circos 图 (biosoft/ViReMa) | `08_dvg/Summary_Analysis_Report/` |
| 9 | report | `generate_pipeline_report.py` | 九阶段汇总: 漏斗/变异/组装/证据 + 图表复制 + AI 解读提示词 | ★ `09_report/Pipeline_Summary_Report.html` |

## 关键参数

| 参数 | 默认 | 说明 | 出处 |
|---|---|---|---|
| `--reference/--ref_info` | 必填 | B3 桥产物 (参考基因组+信息表; 含人工 TaxID 段 9000000+) | auto_known_virus.py |
| `--reads_dir` | 必填 | ② 的去宿主 reads (与 ③ 同源) | 同上 |
| `--tool` | salmon | 定量工具 (kallisto/bowtie2) | 同上 |
| `--snpeff/--snpgenie` | off | 变异注释与 dN/dS 开关 | 同上 |
| `--stage` | — | 9 阶段子集 | 同上 |
| `--io-layout` | legacy | 双布局开关 | 同上 |
| `--filter` | off | 自动联动阶段 2 | 同上 |
| `--dvg_reads` | =reads_dir | DVG 检测专用 reads 目录 | 同上 |
