# 03 · ③ 病毒发现管线 (virome_discovery_pipeline) — 核心管线

**定位**: de novo 病毒发现, 全平台枢纽。15 阶段: 组装 → 10 工具并行鉴定 → 双层过滤 (+ 可选组装图标签传播子步骤) → COBRA 延伸 → 共组装 → 参考引导聚类 → 8 工具分类加权投票 → 三级宿主预测 → CheckV → 四支路级联拯救 → 整合分析 → 证据复核 → 报告。
**主编排器**: `virome_pipeline.py` (唯一入口, `--stage` 选 15 阶段子集)

## 15 阶段逐段解读 (输出目录 = legacy 命名)

| # | stage | 脚本 | 做什么 | 产物 |
|---|---|---|---|---|
| 1-2 | clean/deplete | 调 ② 管线 | 质控 + 去宿主 (与 ② 完全同一份代码) | `00a_CleanData/` `00b_HostDepletion/` |
| 3 | assembly | `assembly_pipeline.py` | MEGAHIT / rnaviralSPAdes / Penguin 三组装器 | `01_Assembly/{sample}/{sample}_{tool}.contig.fasta` |
| 4 | identification | `virus_identification.py` | **10 工具并行**: geNomad、Diamond BLASTX(vs RVDB)、RdRpCatch、ViraLM(DNABERT-2)、VirBot、VirSorter2、ViralVerify、VirHunter、Metabuli、类病毒 BLASTN | `02a_Identification/` 候选 fasta + 各工具明细 |
| 5 | graph | `graph_propagation.py` | **组装图标签传播** (思想源自 GMW 2026): 配对读段链接图 (bwa-mem2, assembler 无关) + 10 工具 ensemble 种子 + Louvain 社区传播 (GMW ≥10 倍多数比) + GC 差/深度比断边 → 逐 contig viral/non-viral 重估 | ★ `03_Filter/graph/{S}.graph_verdict.tsv` (审计列) + `candidates/` 派生候选 |
| 6 | filter | `filter_virus.py` | UniProt-strict / UniRef90+CDD 两层过滤 (filter-first 范式); **末端消费图判定**: 救回被丢弃的 graph_viral / 降级零证据的 graph_nonviral (分层符号链接不动, 审计表逐样本可查) | `02b_Filter/` + `cdd_calls.tsv` + `graph/graph_calls.tsv` |
| 7 | cobra | `cobra_pipeline.py` | BWA-MEM2→CoverM 覆盖度→COBRA-Meta 单样本延伸; raw 候选源在 `graph.apply_to_cobra` 开启时自动切到 `03_Filter/graph/candidates/` (剔除降级 contig, cobra 内部零改动) | `03a_COBRA/` (coassembly 模式自动跳过) |
| 8 | merge | 内置 Flye | 多样本共组装 (`--coassembly`) | `03b_MergeSamples/` |
| 9 | cluster | `cluster_pipeline.py` | CD-HIT **参考引导**预聚类 (挂靠 ICTV/NCBI 已知基因组) + vclust Leiden 聚类去冗余 | ★ `04_CLUSTER/4_centroids/final_centroids.fasta` + vclust_clusters.tsv |
| 10 | taxonomy | `virus_classifier.py` + `virus_classifier_analysis.R` | **8 工具加权投票**: geNomad/Metabuli/CAT/Diamond LCA/VITAP/MMseqs2/ACVirus/vConTACT3 → 8 级分类 + 每级一致度 | ★ `05_Taxonomy/integrated/final_integrated_classification.tsv` |
| 11 | host | `run_host_prediction.py` | ICTV > RNAVirHost > PhaBOX2 三级回退 + 植物专属后过滤 | `06_HostPrediction/ensemble_host_summary.tsv` |
| 12 | checkv | 内置 | CheckV 完整性/MCP 评估 | `07_Checkv/completeness.tsv` |
| 13 | rescue | `rescue_pipeline.py` | **四支路级联**: A: CheckV≥90% 直通 → B: Virseqimprover reads 延伸 → C: BLASTN/PlantVirusDB 参考引导重建 (自动搜 cdhit 库) → D: genus-length 兜底; 宿主预过滤省 70%+ 计算 | ★ `08_Rescue/HQ_plant_viruses.fasta` + `final_judgement_table.tsv` + `centroids/final_centroids.fasta` |
| 14-15 | analysis/verify | `virome_analysis.py` + `integrate_rescue_evidence.py` + `hmm_ct3_evidence.py` | 整合拯救证据; 09b 五层证据复核 (HMM/CT3) | `09a_Virome_Analysis/` `09b_Analysis_Verify/` |
| 16 | report | `report_pipeline.py` | 逐阶段状态扫描 (未跑标 ○) + 漏斗一致性 + Sankey + HTML | ★ `10_Reports/pipeline_report.html` |

## 关键参数 (编排器)

| 参数 | 默认 | 说明 | 出处 |
|---|---|---|---|
| `--input_reads` | — | 去宿主 reads 目录 (B2) | virome_pipeline.py |
| `--output_dir` | 必填 | 项目根 (standard 布局指向 `03_Discovery`) | 同上 |
| `--stage` | — | 15 阶段子集; `--stage all` 全跑 | 同上 |
| `--host_db / --virus_db / --checkv_db` | config | 三类数据库路径 (profile 可覆盖) | 同上 |
| `--host-filter` | — | 宿主类别预过滤 (如 Plant), 拯救前省算 | 同上 |
| `--coassembly` | off | 多样本 Flye 共组装模式 | 同上 |
| `-t/-j` | config | 线程/并行任务 | 同上 |
| `--io-layout` | legacy | 双布局开关 | 同上 |
| `--config/--profile` | pipeline_config.yaml | profile 配置 (plant/downstream 继承 default) | 同上 |

数据库路径全部走 `pipeline_config.yaml` + `${MMPV_*}` 环境变量 (见 [[10-部署与运维]])。

## 上下游

- **上游 B2←②**; **下游 B3→④**: 两个 ★ 文件经 `utils/discovery2analysis.py --from-discovery <③根>` 转成 `reference.fasta + ref_info.tsv` (自动定位, 双布局通吃, 写 90_Handoff 台账)
- **下游 B7↔eve_discriminate**: 09b 在 CDD 验证后、五层证据整合前跑 EVE 判别（默认开）；`EVE_like` 经 `--eve-calls` 把 KEEP 降为 REVIEW；`--eve-faa`/`--eve-exo-dmnd` 可加 Δbit-score。结果并入 `pipeline_report.html` 的 09b 卡片
- **新病毒判定**: 基于分类层级完整度 (taxonomy completeness), 无需 BLASTN
- ③ 的 RVDB 派生库 (diamond/mmseqs/metabuli/CAT) 由 `build_virus_db.py` 现场构建
