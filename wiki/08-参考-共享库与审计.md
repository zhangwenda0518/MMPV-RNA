## `scripts/db_setup/mmpv_db.py`

```text
usage: mmpv_db.py [-h] [--share SHARE] [--repo REPO] [--db-root DB_ROOT]
                  [--plant-root PLANT_ROOT] [--src-root SRC_ROOT]
                  [--fetch-file TSV]
                  {list,which,env,check,verify,layout,adopt,link,publish,down,fetch}
                  ...

MMPV 数据库部署 / 迁移 / 校验工具

positional arguments:
  {list,which,env,check,verify,layout,adopt,link,publish,down,fetch}
    list                打印依赖清单
    which               打印若干 id 的解析路径与状态
    env                 打印/写出环境变量块
    check               部署前体检：可写性、旧路径现状、缺项统计
    verify              逐项校验数据库是否就位
    layout              建规范目录骨架
    adopt               把既有数据库树迁入共享根
    link                建旧路径与仓库侧的兼容软链接
    publish             把仓库侧小文件发布到共享池
    down                按配方下载/构建数据库（换服务器时用）
    fetch               查看某个库的获取方式与配方

options:
  -h, --help            show this help message and exit
  --share SHARE         共享库根（默认 $MMPV_DATA_SHARE 或 ~/mmpv-db）
  --repo REPO           仓库根（默认由本脚本位置推导）
  --db-root DB_ROOT     覆盖 ${MMPV_DB_ROOT}（默认 <share>/database）
  --plant-root PLANT_ROOT
                        覆盖 ${MMPV_PLANT_VIRUS_DB}（默认 <share>/plant_virus_db）
  --src-root SRC_ROOT   上游原始数据目录（默认 $MMPV_SRC 或 <share>/src）
  --fetch-file TSV      用自定义获取配方替换 mmpv_db_fetch.tsv（站点自维护/测试用）

MMPV 数据库部署 / 迁移 / 校验工具

把 MMPV 全管线依赖的数据库集中到一个「共享库根」，使：(1) 换机器/换用户时可复现，
(2) 旧路径（~/database、~/plant_virus_db）通过软链接继续可用，核心代码里那些
硬编码路径无需改动。
```
