# 01 · ① 公共数据管线 (public_metadata_pipeline)

**定位**: 平台数据入口。NCBI SRA + CNCB GSA 双引擎物种检索 → AI 元数据清洗 → 批量下载 → 格式转换 → 可视化 → 宿主参考基因组获取与四索引建库 → HTML 报告与交接清单。

**主编排器**: `public_data_pipeline.py` (8 阶段, `--stage search info down convert plot hostref hostdb report`)
**辅助入口**: `build_host_pipeline.py` (宿主参考单独编排) · `preprocess_unified.py` (convert→clean→deplete 一条龙直达 clean reads)

## 8 阶段逐段解读

| 阶段 | 脚本 | 做什么 | 产物 (下游交接物 ★) |
|---|---|---|---|
| search | `gsa_sra.search.py` | NCBI SRA (esearch) + CNCB GSA (HTTP) 双引擎物种检索, 合并去重; AI 规范化 (非破坏) + 可选 DeepSeek 检索补缺 | `01_Search/SRA_GSA_Merged_Final.csv` (+ `AI_Backfill` 检索溯源 / `AI_Conflict` 冲突列) |
| info | `gsa_sra.info.py` | SRA XML 解析 + GSA 爬虫 + DeepSeek/Kimi AI 元数据清洗补全 (13 列白名单); `--search-backfill` 把 search 段 AI 检索结论并入 | ★ `02_Unified/Global_Unified_Metadata_Core14.csv` (14 列, 全平台元数据唯一权威; ⑤ 直读) + `_Full.csv` 溯源表 |
| down | `gsa_sra.down.py` | NGDC (aria2c/requests/wget) + NCBI (prefetch) 双协议批量下载, 断点跳过 | `03_RawData/` 原始 .sra/.fastq |
| convert | `sra2fastx.py` | fasterq-dump 批量转 FASTQ.GZ, 失败回退 fastq-dump | 配对 FASTQ.GZ |
| plot | `gsa_sra.plot.py` | 时间/组织/地区/机构 6 面板 SCI 级可视化 | `04_Plots/` |
| hostref | `download_host_genome.py` | 宿主基因组四通道下载 (datasets→ngd→FTP→gget 自动回退; `--host-fasta` 可跳过) + GFF3 + 细胞器基因组 | ★ `05_HostRef/genome/all.genome.uniq.fasta` (① 的 `eve` 阶段消费) |
| hostdb | `build_hostbase.py` | Kraken2 + Bowtie2 + HISAT2 + Minimap2 四索引构建 | ★ `05_HostRef/hostdb/` (②③ 的 `--host_db`) |
| report | `generate_report.py` | 汇总各阶段状态 + 宿主参考就绪度扫描 | HTML 报告 + ★ `sample_handoff.csv` (Run→FASTQ+元数据交接清单, B1) |

## AI 规范 (v3.2)

- **非破坏**: AI 只填空 / 补更完整写法 / 规范化; 已有真值与 AI 结论互不包含时保留原文, 冲突写 `AI_Conflict` + `ai_conflicts.jsonl|csv`, 绝不静默覆盖 (旧版"清洗/防火墙"的无条件赋值已移除)。
- **统一来源标记**: AI 写的 `Location` 一律 `_AI` 后缀 (`format_location`), 下游 `metadata_governance` / `plot` 自动剥离。
- **统一溯源**: 每次调用写 `ai_log.jsonl` (op/model/prompt 版本/tokens/latency), 优先落 `<项目>/90_Handoff/state/ai_log.jsonl`, 与平台 AI 驱动层同账本 (`mmpv_ai.py provenance <项目>` 可汇总); 无 `90_Handoff` 时回退产物目录, 或由 `MMPV_AI_STATE_DIR` 指定。
- **检索闭环**: `search --deepseek-search` 的结论经 `AI_Backfill` 列 + `--search-backfill` 并入 Core14 (`_Full` 表新增 `AI_Backfill_Search` 溯源列), 不再止步于 `01_Search` 的 CSV。
- **审计先于成本**: 每类调用有 prompt 版本号登记 (`ai_trace.PROMPT_VERSIONS`), 摘要/推断失败只降级不阻塞管线 (失败同样留痕)。
