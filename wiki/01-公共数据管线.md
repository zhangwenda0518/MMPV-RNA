# 01 · ① 公共数据管线 (public_metadata_pipeline)

**定位**: 平台数据入口。NCBI SRA + CNCB GSA 双引擎物种检索 → AI 元数据清洗 → 批量下载 → 格式转换 → 可视化 → 宿主参考基因组获取与四索引建库 → HTML 报告与交接清单。

**主编排器**: `public_data_pipeline.py` (8 阶段, `--stage search info down convert plot hostref hostdb report`)
**辅助入口**: `build_host_pipeline.py` (宿主参考单独编排) · `preprocess_unified.py` (convert→clean→deplete 一条龙直达 clean reads)

## 8 阶段逐段解读

| 阶段 | 脚本 | 做什么 | 产物 (下游交接物 ★) |
|---|---|---|---|
| search | `gsa_sra.search.py` | NCBI SRA (esearch) + CNCB GSA (HTTP) 双引擎物种检索, 合并去重 | `01_Search/SRA_GSA_Merged_Final.csv` |
| info | `gsa_sra.info.py` | SRA XML 解析 + GSA 爬虫 + DeepSeek/Kimi AI 元数据清洗补全 (13 列白名单) | ★ `02_Unified/Global_Unified_Metadata_Core14.csv` (14 列, 全平台元数据唯一权威; ⑤ 直读) + `_Full.csv` 溯源表 |
| down | `gsa_sra.down.py` | NGDC (aria2c/requests/wget) + NCBI (prefetch) 双协议批量下载, 断点跳过 | `03_RawData/` 原始 .sra/.fastq |
| convert | `sra2fastx.py` | fasterq-dump 批量转 FASTQ.GZ, 失败回退 fastq-dump | 配对 FASTQ.GZ |
| plot | `gsa_sra.plot.py` | 时间/组织/地区/机构 6 面板 SCI 级可视化 | `04_Plots/` |
| hostref | `download_host_genome.py` | 宿主基因组四通道下载 (datasets→ngd→FTP→gget 自动回退; `--host-fasta` 可跳过) + GFF3 + 细胞器基因组 | ★ `05_HostRef/genome/all.genome.uniq.fasta` (⑥ 也消费) |
| hostdb | `build_hostbase.py` | Kraken2 + Bowtie2 + HISAT2 + Minimap2 四索引构建 | ★ `05_HostRef/hostdb/` (②③ 的 `--host_db`) |
| report | `generate_report.py` | 汇总各阶段状态 + 宿主参考就绪度扫描 | HTML 报告 + ★ `sample_handoff.csv` (Run→FASTQ+元数据交接清单, B1) |

## 关键参数 (完整 `--help` 见 [[08-脚本参数参考]])

| 参数 | 默认 | 说明 | 出处 |
|---|---|---|---|
| `--species / --taxid` | 必填 | 物种拉丁学名 + NCBI TaxID (检索与宿主参考共用) | public_data_pipeline.py |
| `--stage` | 必填(多值) | 8 阶段任意组合, `all` 全跑 | 同上 |
| `--deepseek-api / --ncbi-api` | env | AI 清洗与 NCBI 限速 key | 同上 |
| `--work-dir` | `./public_data_pipeline_output` | 输出根 (standard 布局指向 `01_PublicData`) | 同上 |
| `--io-layout` | legacy | I/O 布局开关 (env `MMPV_IO_LAYOUT` 等价) | 同上 |
| `--host-download-source` | auto | datasets/ngd/FTP/gget 回退链 | 同上 |
| `--hostdb-tools` | kraken2,bowtie2,hisat2,minimap2 | 四索引工具集 | 同上 |
| `--convert-jobs/--convert-threads` | 2/6 | fasterq-dump 并行度 | 同上 |
