## `virome_submission_pipeline/analyze_hypothetical.py`

```text
usage: analyze_hypothetical.py [-h] -t TBL -f FAA --blast BLAST [-d DB]
                               [-o OUTPUT] [-tbl-out TBL_OUTPUT]
                               [-faa-out FAA_OUTPUT] [--threads THREADS]
                               [--evalue EVALUE] [--online]
                               [--online-db ONLINE_DB] [--delay DELAY]
                               [--email EMAIL] [--ncbi-api-key NCBI_API_KEY]
                               [--diamond] [--diamond-bin DIAMOND_BIN]
                               [--hmmer] [--hmmer-db HMMER_DB]
                               [--hmmer-bin HMMER_BIN] [--annot ANNOT]
                               [--skip-blast]

analyze_hypothetical.py — 假定蛋白 blastp 功能注释工具 v2.1

options:
  -h, --help            show this help message and exit
  -t TBL, --tbl TBL     featuretable.tbl 路径
  -f FAA, --faa FAA     proteins.faa 路径
  --blast BLAST         blastp 结果输出文件路径
  -d DB, --db DB        blastp 数据库路径 (如 /db/nr 或 /db/uniprot)
  -o OUTPUT, --output OUTPUT
                        输出目录 (默认: ./hypothetical_output)
  -tbl-out TBL_OUTPUT, --tbl-output TBL_OUTPUT
                        更新后的 featuretable 输出路径 (默认:
                        {output}/featuretable_updated.tbl)
  -faa-out FAA_OUTPUT, --faa-output FAA_OUTPUT
                        更新后的 proteins.faa 输出路径 (默认:
                        {output}/proteins_updated.faa)
  --threads THREADS     blastp 线程数 (默认: 8, 仅本地模式)
  --evalue EVALUE       blastp E-value 阈值 (默认: 1e-3)
  --online              使用 NCBI 在线 BLAST (无需本地数据库, 序列多时较慢)
  --online-db ONLINE_DB
                        NCBI 在线 BLAST 数据库 (默认: nr, 可选: uniprotkb, swissprot,
                        pdb)
  --delay DELAY         在线 BLAST 每次提交间隔秒数 (默认: 3; 有 API key 可降至 1)
  --email EMAIL         NCBI 邮箱 (强烈推荐, NCBI 可能限制无邮箱的请求)
  --ncbi-api-key NCBI_API_KEY
                        NCBI API key (提升请求频率上限,
                        https://ncbi.nlm.nih.gov/account/)
  --diamond             使用 diamond blastp 本地高速比对 (配合 -d 指定 .dmnd 数据库)
  --diamond-bin DIAMOND_BIN
                        diamond 二进制路径 (默认: diamond, 需在 PATH 中)
  --hmmer               使用 hmmscan 搜索 HMM 结构域 (配合 --hmmer-db 指定 .hmm 数据库)
  --hmmer-db HMMER_DB   hmmscan HMM 数据库路径 (如 U-RVDBv31.0-prot.hmm)
  --hmmer-bin HMMER_BIN
                        hmmscan 二进制路径 (默认: hmmscan)
  --annot ANNOT         功能注释表 (如 U-RVDBv31.0-prot.info.tab), 将序列ID映射为真实蛋白名
  --skip-blast          跳过 blastp 运行 (直接使用已有的 --blast 文件)

示例:
  # 本地 blastp (快速, 推荐批量)
  python analyze_hypothetical.py \
      -t featuretable.tbl -f proteins.faa \
      --blast my_blast_results.txt \
      -d /db/nr \
      -o ./output/ \
      --threads 16

  # NCBI 在线 BLAST (无需本地数据库)
  python analyze_hypothetical.py \
      -t featuretable.tbl -f proteins.faa \
      --blast my_blast_results.txt \
      --online \
      -o ./output/
```
