# 05 · ⑤ 系统发育/进化/群体遗传管线 (virome_phylo_pipeline)

**定位**: 18 个细粒度 stage, 对外暴露 8 大模块 (`--stage data,popgen,recomb,select,phylogeny,time,geography,report`)。BEAST 1.x 定年 + pypopart 群体遗传 + HyPhy 正选择 + RDP5 重组 + CTMC 系统地理。
**主编排器**: `phylo_pipeline.py` (96 个 CLI 参数; 三入口 `--extract_dir`(批量, 接 ④ 的 06_Extraction) / `--virus`(datasets.yaml 注册表) / `--work_dir`(单病毒续跑))

## STAGE_ORDER 与依赖 (代码 `STAGE_ORDER`/`STAGE_DEPS` 逐字)

```
prep → metadata → online → clean → align ─┬→ splitstree → rdp5 → tree
                                          ├→ popgen → host
                                          └→ capheine
tree → clock → beast → gene_dating ; tree → phylogeo → geo_paths ; tree → geo ; tree → host
全部 → report
```

| 模块 | stage | 内容 |
|---|---|---|
| data | prep→metadata→online→clean | 样本/参考序列合并; **入口元数据治理** (日期格式白名单+精度分档, 地理层级校验+坐标补算, 治理值三通道回填 dates/sample_metadata/host.csv); NCBI 参考补充 (efetch+SeqHarvester); 比对前清洗 |
| phylogeny | align→splitstree→tree | MAFFT 全长比对 + 替换饱和分析 (Iss); SplitsTree6 NeighborNet (树状/网状信号判别); IQ-TREE (MFP) 建树 |
| popgen | popgen→host | pypopart: π/θ_w/Tajima's D/Fu's Fs/Fst/MJN 单倍型网络; 宿主分化分析 (仅 host 非空样品) |
| recomb | rdp5 | RDP5 重组检测 + 事件校验 + 可选 mask (masked_N.fasta 回注比对) |
| select | capheine | 正选择: CAWLign 密码子比对→IQ-TREE→HyPhy aBSREL/FEL/MEME/BUSTED→DRHIP 汇总 |
| time | clock→beast→gene_dating | **时间信号门禁**: TreeTime-RTT/TreeDater-LTT/替代饱和(DRT)/BETS — 不过门禁自动跳过 BEAST; BEAST 1.x 定年 (skyline/bdsky/constant, 分链合并 LogCombiner+TreeAnnotator); 分基因 BEAST 定年 |
| geography | phylogeo→geo→geo_paths | CTMC+BSSVS 系统地理 (MCC 树+扩散路径); 地理分析 (遗传-地理相关/先验比较); 事件级传播路径 (吃 phylogeo 的 mcc.tree) |
| report | report | phylo_summary.csv + phylo_report.html + 单倍型发表图全套 (交互 HTML/地图/统计) |

## 单倍型状态热图 (popgen stage, hastat 论文 Fig.2 构图, 2026-10-22)

`03_popgen/popgen_stats.hap_state_heatmap.{pdf,png,svg}` — 单倍型×多态位点
ACGT 四色栅格 (行按频次降序; 位点 >400 等距抽稀), 自上而下五层, 全部共享
基因组横轴:

1. **Fst 轨道 (按群体两两)**: 每条线一个群体对 (`A|B` 命名, 图例标对名)
2. **π 轨道 (按群体)**: 每条线一个群体; 无元数据时退化为单一全体 π 轨道
3. **基因结构带** (`--genes-csv` 或 datasets.yaml 的 `genes_csv` 提供时):
   CDS 黑块 / UTR 灰块 / 内含子箭头 (链向感知) + 5′/3′ 与基因名; 下缘
   红色倒三角逐列标出**变异位点**; **逐位点引线**: 基因覆盖的每一列引一条
   虚线到矩阵对应列 (论文 Fig.2 构图), 每基因 ≤60 列时全画, 过密按 stride
   抽稀 (线间距 < 线宽会糊成灰幕)
4. **单倍型等位状态矩阵**: 位点多时为纯栅格, ≤40 列时格子旁有位点编号;
   左侧行色条按该单倍型的**主导群体**着色 (无元数据时无色条)
5. **横轴**: 多态位点编号 (5′→3′)

轨道算法口径: π 用 pairwise deletion (仅 ACGT); Fst 用 Hudson 1992
(scikit-allel, 双等位列筛选、多等位保守跳过); 窗口按比对列滑动, 窗口数
超 400 时 step 自动倍增。CLI: `--window/--step` (默认 100/50), `--no-tracks`
或 `--window 0` 关闭; 配色 Okabe-Ito 色盲安全。

构图参考 hastat (`plot gene`, Horticulture Research 2026, uhag018); 基因带
配色与 EasyHap 口径一致。测试锁定: `tests/test_popgen_stats.py`
(sliding_tracks 按群体/群体对结构、Fst 中间值非哑值、**轨道横轴映射到矩阵
列号**、逐位点引线、渲染五层齐出)。

注: π/Fst 轨道条数与行色条颜色数 = 群体数。单群体数据集 (如 PSTVd 公共数据)
客观上只有一个 π 轨道、无色条 —— 这是数据维度决定, 非缺陷; 多群体数据集
(如 GCVA 6 群体) 自动出论文式多线多彩形态。

## 关键机制

- **时间信号门禁**: RTT/LTT/DRT 不达标 → 跳过 BEAST (避免伪定年), 结果标 skipped
- **文档权威体系**: 六文档各管一件事 (README 入口 / RUN_GUIDE 参数 / STAGE_REFERENCE 逐 stage / PIPELINE_FLOW 数据流 / METHODS 论文表述 / RUNNING_PROCESS 叙事), `verify_docs_vs_code.py` 自动对拍
- **metadata 治理**: 日期白名单+精度分档、地理层级校验、占位符坐标补算后清空 — 治理产物按样品名回填三通道表

## 关键参数 (节选, 全 96 个见 --help)

| `--rdp5_mask` | 重组 mask 后回注比对 | 同上 |
| `--bets` | 已归档止损的 BETS 路线哨兵开关 | 同上 |
